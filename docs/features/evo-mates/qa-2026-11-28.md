Each journey ran on a clean scratch agent folder, as a person would use the
app. Screenshots are named below by file; they were taken in the session's
scratch folder and the key ones are copied to the group's shared notes folder
(`mates-qa-shots/`); they are not committed.

Severity: **S1** loses data, money or trust (a silent model switch, another
app's list polluted) · **S2** a requirement not met or a clear UX fault ·
**S3** polish.

## Questions for the owner

- **Q1** Should a mate's saves to its *own* memory ask under "Ask every
  time"? Today every "remember that…" stops on an approval card, which is
  heavy for a daily user; the journal with Undo (learning-layers) makes a
  silent save reversible. Recommended: a mate's own memory saves without a
  card, the person's general memory still asks. Permission change: not made.
- **Q2** Should read-only commands outside a mate's folder ask first? A
  mate grepped the whole home folder without asking. Recommended: for mates,
  reads outside the mate's or channel's folder ask once per conversation.
  Permission change: not made.
